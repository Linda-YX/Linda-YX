# Leaf Green 界面同步验收

参考用户提供的 `finance-four-tabs-green-icons-v2.html` 和 `finance-feature-text-preservation-audit.md`。在现有 React 页面上同步视觉，不使用样板中的 iframe、静态金额或演示按钮实现。

## 变更范围

- 统一叶绿色主题、渐变净资产卡片、绿色图表与持仓配色、圆角账户卡片、标题和数字排版。
- 四个导航使用 SVG 图标，显示名改为「财务总览 / 我的账户 / 投资分析 / 数据导入」；内部 page id 和原页面标题保留。
- 保留 `finances.` 品牌及全部全局操作。手机端保留四个导航图标、表格横向滚动和原有数据操作入口。
- 先纳入仓库已有的 `741316c` 总览视觉修改，再通过独立 `src/theme.css` 应用新版视觉。
- 数据模型、计算、解析器、状态更新、编辑器与导入业务代码未改；保留 `finances-local-v1`，没有迁移、重置或重写浏览器数据。

## 文案与功能保留

以改版前 main `1c07680` 为基准，用 TypeScript AST 对照 App、Dashboard、Reports、Editors、ui、model、importers 中的中文 JSX 文本、字符串和模板片段：527 个原片段均仍存在，缺失 0。新增四个导航名，原标题仍保留。这个源代码对照涵盖未必在默认页面显示的校验、提示、帮助与条件文案；它不代替运行时测试。

原有功能测试涵盖：CSV/PDF/手动导入、重复文件、确认前余额不变、取消、同日余额替换与审计、外币元数据、投资筛选及季度/年度、备份与清空、损坏存储保护、三种弹窗 X/取消/Esc 和未保存内容处理、空账户删除、有历史账户归档及保留历史。

新增浏览器测试覆盖：

1. 已有非演示记录在四页导航及刷新后逐字节保持不变，原标题、导航 SVG 和本地模式提示仍在。
2. 全空状态的账户、持仓、投资分类、导入帮助和三个导入入口。
3. 缺汇率、超过 30 天、展开账户历史、无比较基准时显示「—」，以及金额变化不等于投资回报的原说明。
4. 超过 20 MB 的虚构文件被拒绝且不写入数据；待核对导入可刷新恢复，Esc 明确确认放弃后取消，余额、持仓及审计不变。

新增待核对测试初次运行错误地假定 CSV 核对窗可直接 Esc 关闭；实际原逻辑会要求确认放弃。已修正测试以验证这个保护提示，没有修改业务逻辑。

所有测试只使用仓库虚构示例、虚构 PDF 和内存生成的虚构 CSV。未读取或上传用户真实财务文件。
