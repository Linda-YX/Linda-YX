# 本地审查：弹窗关闭与账户归档 / 删除

本次修改仅供独立审查分支 `review/dialog-close-account-archive` 检查，不合并到 main，不更新 GitHub Pages。所有验证均使用虚构账户、仓库内虚构 PDF 和内存生成的 CSV，没有使用或上传用户真实财务文件。

## 版本核对与复现

修改前本地 HEAD、远程 main 均为 `a6e8784f2f8154d636736e7a622dcbfa8c0cfe2e`；远程 gh-pages 为 `a6e85a9a99605769335037abeb3609ad3e6bf47f`。线上 HTML、入口 JS 和 CSS 与修改前本地生产构建逐字节相同。

分别在开发版本和与线上一致的生产构建中，检查三个窗口的 X、取消、Esc，共 18 条关闭路径。没有复现余额窗口无法关闭。已确认的缺口是：填写余额后关闭会直接丢弃内容，没有未保存提示。

## 修复范围

- 三个窗口共用关闭入口。未编辑时直接关闭；有未保存内容时提示“继续编辑 / 放弃更改并关闭”。确认框自身按 Esc 或 X 只返回编辑，不会关闭底层表单。
- 取消按钮均为 `type="button"`，与 X、Esc 使用相同关闭逻辑；保存成功才走明确的提交路径。导入取消将最近导入标记为“已取消”，不把核对页编辑提交为余额或持仓。
- 空账户可确认删除；任何余额 / 持仓历史（包含被替换或未确认记录）均阻止删除。有历史账户只显示归档。
- 归档立即从当前列表、合计、当前持仓、行业 / 地区敞口和录入选项中移除账户。账户本身及余额、持仓、导入、审计记录均保留，在“已归档账户”可查阅历史。
- 历史是按估值日组织：归档当天及此前已保存的历史图表不重算为零；归档日之后的估值日期排除此账户。当前合计则立即排除。界面明确说明这一边界；统计范围变化时不把归档造成的差额当作资产增长。
- 存储版本仍为 v1，新增归档状态和可选日期字段，原有账户及记录无需迁移。

## 取得审查版本

分支：`review/dialog-close-account-archive`。需要 Node.js 22.13+，推荐 Node.js 24。

```sh
git clone --branch review/dialog-close-account-archive --single-branch https://github.com/Linda-YX/Linda-YX.git finances-review
cd finances-review
npm ci
npm run dev -- --port 5173
```

也可以在此分支页面点击 **Code → Download ZIP**，解压后在包含 `package.json` 的文件夹打开终端，执行上述 `npm ci` 和 `npm run dev -- --port 5173`。这会在自己的电脑启动预览，不会更新线上网站。

## 本地预览与手工检查

在项目目录运行：

```sh
npm ci
npm run dev -- --port 5173
```

然后在运行该命令的电脑浏览器打开 `http://localhost:5173/`。当前云工作区为 `/workspace/Linda-YX`，该服务也已在云环境内启动；当前聊天没有浏览器预览或端口转发入口，云环境内的 localhost 地址不能直接当作用户电脑上的预览链接。

建议用新的浏览器隐私窗口检查虚构示例：

1. “记录余额”输入任意虚构金额，分别尝试 X、取消、Esc；选择继续编辑时金额保留，选择放弃后净资产不变，重新打开余额输入为空。
2. “添加账户”和“报告导入 → 手动输入 → 继续到核对”同样检查关闭提示；只输入虚构名称和金额。
3. 账户页对没有历史的 Rogers 示例账户先取消删除，再确认删除；账户消失，净资产不变，刷新后仍保持删除。
4. 对 Wealthsimple TFSA 示例账户确认归档；当前净资产从 $72,640 变为 $46,500，过去的净资产图表数值仍保留。该账户出现在已归档区，8 条余额 / 持仓历史可查，不再出现在余额或导入账户选项中。

审查通过前不要运行 `npm run deploy:pages`，也不要推送 gh-pages。
